I'm **tukmogi**. I break things and write up how I did it.

This blog is where I keep notes on the boxes and challenges I've worked through
— mostly [HackTheBox](https://www.hackthebox.com/) machines and CTF web
challenges. The writeups aim to show the reasoning, not just the winning
command: the enumeration that went nowhere, the thing that finally clicked, and
the code review that explained why.

## What you'll find here

- **HackTheBox writeups** — retired machines, start to root.
- **CTF writeups** — mainly web exploitation.
